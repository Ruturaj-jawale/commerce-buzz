# Changelog

## Current Direction

The project is evolving from a universal commerce analytics MVP into a multi-tenant commerce, payments, and revenue-recovery analytics platform.

Major planned areas:

- Secure user sessions
- MCP Streamable HTTP and OAuth
- PostgreSQL migrations
- Reliable ingestion
- Idempotency
- Webhook verification
- Universal payment model
- Revenue-at-risk analytics
- Recovery analytics
- Production authorization
- Audit logs
- Rate limiting
- Billing
- Monitoring
